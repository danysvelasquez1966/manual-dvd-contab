1. Introducción

DVD CONTAB es un sistema contable profesional diseñado para pequeñas y medianas empresas venezolanas. Automatiza:

  • El registro contable por partida doble
  • Los libros fiscales exigidos por el SENIAT
  • Los estados financieros bajo NIIF
  • El cálculo de impuestos (IVA, ISLR, IGTF, IGP)
  • El cierre contable y los ajustes por inflación
Regla de oro: Todo ingreso de datos alimenta automáticamente los demás módulos. No hay que repetir información.

2.2 Instalación Paso a Paso

Paso 1 — Instalar Python

  1. Descargue desde python.org/downloads
  2. Marque "Add Python to PATH"
  3. Clic en "Install Now"

Paso 2 — Instalar librerías

pip install openpyxl
pip install Pillow
pip install reportlab

Paso 3 — Crear carpeta

En el Escritorio, cree: DVD Contab con subcarpetas BACKUPS y Reportes_Contables.

Paso 4 — Ejecutar

cd /d "C:\Users\TuUsuario\Desktop\DVD Contab"
python sistema_contable_dvd.py

5. Descripción de Módulos

5.1 Contabilidad

Función: Registro de asientos contables por partida doble.

Valida: Debe = Haber, formato de fecha, glosa obligatoria.

5.2 Plan de Cuentas

Función: Administrar el catálogo de cuentas.

5.3 Registrar Compra

Función: Registrar facturas de compra con datos SENIAT.

Genera automáticamente: Registro en Libro_Compras + Asiento contable.

5.4 Registrar Venta

Función: Registrar facturas de venta.

Genera: Registro en Libro_Ventas + Asiento contable.

5.5 Libro de Compras

Reporte fiscal en formato SENIAT. Exportable a Excel.

5.6 Libro de Ventas

Reporte fiscal en formato SENIAT. Exportable a Excel.

5.7 Registros IVA

Cálculo de IVA a pagar o excedente a arrastrar.

5.8 Cálculo ISLR

Estimación del ISLR con tarifas progresivas según LISLR.

5.9 Balance de Comprobación

Verifica que Debe = Haber. Detecta saldos anómalos.

5.10 Estado de Resultados

Formato NIIF 18 con las 3 categorías: Operación, Inversión, Financiación.

5.11 Balance General

Estado de situación financiera (siempre acumulado).

5.12 Cálculo Inventario

Costo de venta + IGP (Impuesto a los Grandes Patrimonios).

5.13 Libro Mayor General

Todos los movimientos por cuenta.

5.14 Mayor Analítico

Detalle cronológico de una cuenta específica.

5.15 Cierre Contable

Cierre del ejercicio + Ajuste por Inflación + NIIF PYMES.

5.16 Configuración

Backups, restauración, calculadora de activos.

5.17 Notas C/D

Notas de Crédito y Débito (clientes y proveedores).

5.18 Admin. Recursos

Gestión de usuarios y contraseñas.

5.19 Auditoría

Registro histórico de todas las acciones.

5.20 Cerrar Sesión

Vuelve a la pantalla de Selección de Empresa.

5.21 Salir del Sistema

Cierra el programa completamente.

8. Preguntas Frecuentes

¿Cómo hago una copia de seguridad? Menú → Configuración → Crear Backup Manual.

¿Los reportes se exportan a Excel? Sí, todos tienen botón "Exportar Excel".

¿Puedo trabajar con varias empresas? Sí, al iniciar se elige la empresa.

¿Cómo registro una retención de IVA? Marque el checkbox en Registrar Compra.

¿Qué es el ajuste por inflación? Reexpresa activos no monetarios usando INPC del BCV.
